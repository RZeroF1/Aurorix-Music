# Task State Template

Use this template only in `AGENTS/state/`; do not commit populated task state.

## Task

Short task name and intended outcome.

## Scope

Affected public paths and explicitly excluded paths.

## Current Status

What is complete, in progress, blocked, or waiting for a decision.

## Validation

Commands or checks run, with publication-safe results only.

## Handoff

The next safe action, open questions, and any required maintainer decision.
