# Public FFI Schema

This directory contains the public bootstrap envelope and the reviewed Home
value projection. `HomeSnapshotV1` is carried by the existing
`ExtensionRequestV1` arm with namespace `aurorix.home` and payload schema
version `1`. It expresses bounded snapshot values and command DTO shapes; it
does not define Home queries, reducers, Provider runtime, playback, or a
native ABI operation.

The Rust mapping in `src/transport.rs` is hand-written and reviewed because
generated Rust/C#/C outputs are not checked into this repository. The pinned
generation contract remains in `ffi-generation.toml`; descriptor and binding
outputs, when generated by the toolchain, belong under ignored `generated/`
and must not be hand-edited.

Unknown schema/projection versions, enum values, oneof arms, fields, duplicate
singular fields, malformed values, and exceeded message/event limits are
rejected. Private planning material must not be copied into this directory,
generated output, commits, or CI logs.
